# Xactimate Reconstruction Estimator

Windows Forms application for converting mitigation estimates into reviewed reconstruction estimates.

## Milestones
1. WinForms UI, drag-and-drop and activity status
2. Xactimate PDF import and parsing
3. Reconstruction mapping and scope review
4. Authorized regional Xactimate pricing integration
5. PDF estimate generation
6. Signed release updates and notification bell
7. Validation with real-world estimates

## Pricing
Xactimate Desktop/X1 does not automatically grant third-party API access. Use only authorized pricing exports or separately licensed API access. Flag missing prices rather than inventing prices.

## Status
Milestone 1 scaffold pushed. PDF parser, pricing, updater, and PDF export are not implemented. Build verification pending GitHub Actions.
